# Java Swing Calculator

A simple desktop calculator application built using Java and Swing.

## ✨ Features
* Basic arithmetic operations (+, -, *, /)
* Decimal support
* Clean UI and event handling (`ActionListener`)
* Clear and delete functions

## 🛠️ Technologies
* Java, Java Swing
* IntelliJ IDEA

## 🚀 How to Run
1. Clone the repo: `git clone https://github.com/Kalpani2004/Java-Calculator.git`
2. Open in IntelliJ IDEA and run `Main.java`.
